# Web の基本

## セッション Cookie
- **一言で**：ログインした人に渡す「番号札」。ブラウザが毎回自動で見せるので、サーバーは「誰か」が分かる。
- **たとえ**：遊園地の再入場のリストバンド。
- **このアプリのどこ**
  - 番号札を渡す：`app/routers/auth.py` の `request.session["user_id"] = user.id`
  - 番号札を読む：`app/security.py` の `get_current_user`
  - 署名の設定：`app/main.py` の `SessionMiddleware`（`SECRET_KEY` で署名するので偽造できない）
- **確かめる問い**
  - Web のサーバーは、なぜ番号札がないと「誰か」が分からないのか？
  - 番号札に「名前」や「役割」まで書かず、番号だけにしているのはなぜ？

## FastAPI のルーティング
- **一言で**：「この URL にこの方法で来たら、この関数を動かす」という対応表。
- **たとえ**：駅の案内板。行き先（URL）ごとに乗り場（関数）が決まっている。
- **このアプリのどこ**：`app/routers/auth.py` の `@router.get("/login")` など。`※ 未習` の印がある。
- **確かめる問い**
  - 同じ `/login` でも、`GET` と `POST` で別の関数が動くのはなぜ？
  - `Depends(...)` は何をしている？（ヒント：`app/security.py` の `require_*` 関数）

## 404 と 403 の使い分け
- **一言で**：404 は「そんなものはない」、403 は「あるけど、あなたは使えない」。
- **たとえ**：他の家の部屋は「そもそも見せない」（404）。自分の家の中で鍵のかかった棚は「あるのは分かるが開けられない」（403）。
- **このアプリのどこ**：`app/security.py` の `require_course_member` などの上。`※ 未習` の印がある。
- **確かめる問い**
  - 学生が他の班のページを開いたとき、403 を返すと何が漏れる？

## Jinja2 テンプレート
- **一言で**：HTML の中に `{{ 変数 }}` や `{% if %}` を書き、Python の値を埋め込む仕組み。
- **たとえ**：差し込み印刷のひな形。
- **このアプリのどこ**：`app/templating.py`（設定）と `app/templates/*.html`。
- **確かめる問い**
  - 学生に教員の項目を見せない処理は、テンプレートで隠すだけで十分？　サーバー側の何と組み合わせている？

## ES Modules
- **一言で**：JavaScript のファイルどうしで `import` / `export` を使って関数を貸し借りする書き方。
- **たとえ**：部品ごとに箱を分け、必要な箱だけ取り出して使う。
- **このアプリのどこ**：`app/templates/base.html` の `<script type="module">` と `app/static/js/`。
- **確かめる問い**
  - 1 つの大きな JS ファイルに全部書くのと比べて、何が楽になる？
