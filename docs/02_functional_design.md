## 1. ロールと権限
| できること | 教員 | 学生 |
|---|---|---|
| 授業をつくる・招待コードを発行する | ○ | × |
| コードで授業に参加する | — | ○ |
| 班を分ける | ○ | × |
| 班にフレームワークを指定してボードを作る | ○ | ×（後で自由に選べる形を足す。D-008） |
| 個人ワークの時間を決める・早めに公開する | ○ | × |
| 自分の班のボードに書く | ×（見るだけ。D-011） | ○ |
| 個人ワーク中の付箋を見る | ○（全員分。D-011） | 自分の分だけ |
| 他の班のボードを見る | ○（全班） | ×（案。Q6） |
| ダッシュボードを見る | ○ | × |

## 2. 一方通行の原則（D-005）
- 教員からは学生の中身が見える。学生からは、教員の画面にも他の班の中身にも入れない。
- 画面で隠すだけにしない。サーバーが毎回ロールを確かめ、見せてはいけないデータはそもそも送らない。
- 返し方を分ける。
  - **404（見つからない）**：存在を知られたくないもの。他の班・担当外の授業。
  - **403（禁止）**：存在は知っていてよいが、操作はできないもの。学生が自分の授業の班分けを開いたとき。

## 3. 授業の流れ
### 教員
1. 授業をつくる → 招待コード（例 `K7Q2MX`）が出る
2. 学生が集まったら班に分ける（手動 / ランダム）
3. 班にフレームワークを指定してボードを作る（例：ブレスト）
4. 個人ワークの時間を決めてスタートする → 時間が来たら自動で公開（早めることもできる）
5. 各班のボードを見守る（個人ワーク中も全員分見える）
6. ダッシュボードで、各班がフレームワークの中でどう考えたかを見る

### 学生
1. 初回は「招待コード + 名前 + パスワード」で登録して授業に入る。次からは「名前 + パスワード」でログインする
2. **個人ワーク**：他の人の付箋が見えない状態で、自分の考えを付箋に書く。残り時間が表示される
3. **公開**：時間が来ると、全員の付箋が作成者名つきで見える
4. **まとめる**：似た意見を重ね、一言の見出しをつける
5. **投票**：大事だと思う付箋・まとまりに投票する
6. **結論**：班としての結論を書く

## 5. 機能ごとの決まりごと
### F-03 招待コード
- 6 文字。英大文字と数字。紛らわしい文字（0・O・1・I・L）は使わない。
- 再発行すると古いコードは使えなくなる。参加済みの学生はそのまま。

### F-04 参加
| 入力された名前 | パスワード | 結果 |
|---|---|---|
| まだ使われていない | — | 学生として登録し、授業に参加 |
| 学生が使っている | 合う | その人として授業に参加を追加 |
| 学生が使っている | 合わない | エラー「その名前は使われています」 |
| 教員が使っている | — | エラー「その名前は使われています」 |

名前は全体で重複できない（ログイン名を兼ねる）。

### F-05 ランダム班分け
- 班の数を指定すると、班の人数の差が 1 以下になるように振り分ける。
- 1 つの授業の中で、学生が入る班は 1 つだけ。

### F-09 進め方（フェーズ）の移り方
```
個人ワーク ──(時間切れ / 教員が早める)──> 公開 ──> まとめる ──> 投票 ──> 結論
```
- 使うフェーズと順番は、フレームワークの定義で決まる（[フレームワーク設計書](06_framework_design.md)）。
- タイマーはサーバーが持つ。終了予定時刻を DB に保存し、時間が来たらサーバーが公開に切り替える。画面は残り時間を表示するだけ。
- 公開より後のフェーズを誰が進めるかは未決（Q14）。

### 付箋の見え方（P1：個人で考える時間を守る）
| フェーズ | 書いた本人 | 同じ班の他の学生 | 教員 |
|---|---|---|---|
| 個人ワーク | 見える・書ける | **見えない（サーバーが送らない）** | 見える（書けない） |
| 公開以降 | 見える・書ける | 見える（作成者名つき） | 見える（書けない） |

- 付箋の本文を直せるのは書いた本人だけ（案）。
- 公開後は、まとめるために他の人の付箋も動かせる（案。Q15）。

### F-10 まとめる
- 付箋を別の付箋の上に落とすと、まとまりになる。見出しは手で書く。
- LLM で候補を出す形は後で足す。データの形はここで作ったものをそのまま使う。

### F-11 投票
- 1 人の票数はフレームワークの定義で決める（例：3 票）。
