## 1. 方針
- **Teams のイメージ**：左に授業、その右に班、メインにボード。
- **見なくていいものはたたむ**：学生には自分の班しか出さない。教員の項目は学生に出さない。
- **今どの時間かが一目で分かる**：ボードの上に、今のフェーズと残り時間を常に出す。

## 2. 全体の配置
```
+--------+------------------+------------------------------------------+
| 授業    | 経営戦略論 #3     | タブ: [ブレスト] [SWOT] [ペイオフ]          |
| 一覧    |                  | 個人ワーク中 残り 4:32（0:00 で自動公開）     |
|        |  * 1班           |   +----------------+----------------+    |
| (Teams |    2班           |   | 強み S          | 弱み W          |    |
|  の     |    3班           |   | [付箋: 学生A]   |                |    |
|  チーム)|  --------------  |   +----------------+----------------+    |
|        |  教員のみ:        |   | 機会 O          | 脅威 T          |    |
|        |   メンバー管理     |   +----------------+----------------+    |
|        |   ダッシュボード   |                                          |
+--------+------------------+------------------------------------------+
```
| 場所 | 中身 | 学生 | 教員 |
|---|---|---|---|
| 左端のレール | 参加している授業 | ○ | ○ |
| 2 列目 | 班の一覧（Teams の「チャネル」） | 自分の班だけ | 全班 + 教員の項目 |
| メイン | 班のボード。タブ 1 つ = フレームワーク 1 つ | ○ | ○（見るだけ） |

使うのはパソコンだけ。スマホは考えない（D-043）。画面の幅は 1280px 前後を基準にする。

### 2.1 授業の中の 3 つの場所（D-036）
2 列目を、次の 3 つの見出しではっきり分ける。設定（準備）と、授業で使う画面を混ぜない。

| 場所 | 2 列目に出る項目 | 学生 | 教員 |
|---|---|---|---|
| ⚙ 準備（設定） | 授業の設定（名前・招待コード）／メンバーと班／フレームワークを探して選ぶ／授業の流れ | 出さない | ○ |
| ▶ 授業中 | 班の一覧（学生は自分の班だけ） | ○ | ○ |
| 📄 成果 | まとめシート（学生は自分の班だけ）／ダッシュボード（教員だけ） | ○ | ○ |

## 4. 画面の移り方
```
S-01 ログイン ──(教員)──> S-03 授業のホーム ──> S-05 メンバー管理
   │                         ├─> S-07 フレームワークを選ぶ ──(配る)──> 全班にボード
   │                         ├─> S-06 班のページ
   │                         └─> S-04 授業の作成
   │
   └─(初めての学生)─> S-02 授業に参加 ──> S-03 授業のホーム ──> S-06 自分の班のページ
```

## 5. ボード画面の要素
| 要素 | 中身 |
|---|---|
| フェーズ表示 | 今のフェーズ名と残り時間。個人ワーク中は「他の人の付箋はまだ見えません」と出す |
| 区画 | フレームワークの定義どおりに並ぶ。区画名とヒントを出す |
| 付箋 | 本文・作成者名。作成者ごとに色を変える |
| 付箋を足す | 区画の中でダブルクリック、または「＋」ボタン |
| 教員の表示 | 教員には書き込みボタンを出さない。上に「閲覧中」と出す |

## 6. フレームワークを選ぶ画面（S-07a・S-07b）
D-036 で 2 つの画面に分けた。最新の形は見本（`docs/mockups/frameworks.html`）を見る。下の絵は分ける前の版。
```
+--------------------------------------------------------------+
| [ブレ                         ]   ← 打つたびに下が絞られる       |
|--------------------------------------------------------------|
| ★ [ブレ]インストーミング   発想・発散    12 回使われています  [選ぶ] |
|    別名: [ブレ]スト・アイデア出し                               |
|--------------------------------------------------------------|
| 選んだもの（タブの順）                                          |
|  1. ブレインストーミング                                        |
|     進め方: [x]個人ワーク [x]公開 [x]まとめる [ ]投票 [x]結論      |
|            （個人ワークと公開は外せない）                        |
|                                              [全班に配る]     |
+--------------------------------------------------------------+
```
- 検索窓が空のときは、よく使われている順に全部並ぶ。
- `[ブレ]` は、打った文字に合った所の強調。

## 7. 見た目
- 色は Teams に寄せる：左のレールは濃い紫（#464775 付近）、2 列目は薄いグレー、メインは白。
- 色・余白・角丸は CSS の先頭に変数としてまとめ、あとで変えやすくする。
