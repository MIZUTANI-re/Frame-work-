## 目的
先生が授業の「準備」の中で、フレームワークを言葉で探して選び、授業の流れ（順番と進め方）を決めて、全部の班に配れるようにする。設定の画面と、授業で使う画面をはっきり分ける。

## 作るもの
1. **画面を 3 つの場所に分ける**（D-036・画面設計書 §2.1）
   - 2 列目を「⚙ 準備（設定）」「▶ 授業中」「📄 成果」の見出しで分ける。
   - ⚙ 準備（先生だけ）：授業の設定（名前・招待コード）／メンバーと班／フレームワークを探す／授業の流れ。今の「授業のホーム」と「メンバー管理」は、ここに移す。
   - ▶ 授業中：班の一覧（学生は自分の班だけ）。
   - 📄 成果：「まとめシート」「ダッシュボード」の置き場だけ（「ステップ 5 で作ります」と出す）。
2. **フレームワークの定義ファイル**（フレームワーク設計書 §2）
   - `app/frameworks/brainstorm.json`・`swot.json`・`payoff_matrix.json`。中身は見本 v2 の定義をもとに、`meta` と `yomi` まで全部埋める。
   - 起動のときに読み込み、仕様に合わない（必須の項目が無い・`board_type` が `zone` / `axis` 以外・`key` とファイル名が違う など）なら起動を止める。
3. **フレームワークを探す**（S-07a・F-06・D-022）
   - 候補の一覧は、サーバーが画面に埋め込み、ブラウザの JavaScript で絞る（打つたびに絞る）。
   - 文字をそろえる：全角と半角、大文字と小文字、カタカナとひらがな。探す対象は、名前・別名・読み（`yomi`）・タグ・説明・目的。
   - 並び順：検索窓が空なら、よく使われている順（全部の授業で選ばれた回数）。文字があるなら、機能設計書 §5 F-06 の順。
   - 合った文字を強調する。「○ 回使われています」を出す。
   - 「流れに足す」でその授業の流れの最後に足す。Event `framework.selected`（そのとき打っていた言葉も入れる）。
4. **チャットの枠**（F-20・D-037・D-042）
   - 「探す」画面の一番下に置く。ChatGPT や Claude のような形にする。
     - 会話は吹き出しで並ぶ（自分は右）。
     - 下に複数行の入力欄と「送る」ボタンを置く。Enter で送り、Shift + Enter で改行する。
   - 送った文は `ChatMessage` に保存する。続けて、決まった返事「LLM はまだつながっていません」を `role=assistant` で保存して出す。
   - LLM は呼ばない（D-016）。Event `chat.posted`。使えるのは担当の先生だけ。
5. **授業の流れ**（S-07b・D-032）
   - 流れに入っているものを順番に並べる。↑↓ で並べ替え、要らない進め方を外し、まだ始まっていないものを流れから外す。
   - 個人ワークと公開は外せない（D-023）。画面だけでなく、サーバーでも確かめる。
   - 「全班に配る」を押すと、全部の班に、流れのフレームワークごとのボード（Board）を作る。① を `active`、ほかを `waiting` にする。
   - あとから作った班にも、その授業の流れのボードを作る。
6. **班のページ**（S-06）
   - 上に、流れの帯（① ブレスト → ② SWOT → ③ ペイオフ と、その状態）を出す。
   - その下に、配られたボードのタブを出す。盤面は「ステップ 2b で作ります」の置き場だけ。
7. **テーブル**：`CourseFramework`・`Board`・`ChatMessage` を Alembic の版 0002 で足す（データ設計書のとおり）。

## 作らないもの
- 付箋・盤面・WebSocket（ステップ 2b）
- 「次へ」で流れを進める・個人ワーク・タイマー（ステップ 3）
- 2 軸型の盤面（ステップ 4）、まとめシート（ステップ 5）
- LLM・おすすめの「テーマに合うもの」「一緒に使われているもの」（D-016・Q16）
- スマホ向けの作り（D-043）

## 完了の条件（テストで確かめる）
- [ ] 学生の 2 列目に「⚙ 準備」が出ず、準備の URL を開くと 403 か 404
- [ ] 定義ファイルが仕様に合わないと、起動が止まる（テスト用の壊れた定義で確かめる）
- [ ] 検索窓が空のとき、よく使われている順に並ぶ（選ばれた回数を作って確かめる）
- [ ] 「ぶれ」「ゆうせん」「ＳＷＯＴ」で、それぞれブレスト・ペイオフ・SWOT が出る（文字をそろえる関数のテスト）
- [ ] 「流れに足す」で流れの最後に入り、`framework.selected` が記録される
- [ ] チャットに送ると、送った文と決まった返事の 2 行が保存される。学生と担当外の先生は送れない
- [ ] 個人ワーク・公開は、画面の操作を通さずに送っても外せない
- [ ] 「全班に配る」で、全部の班に流れの数だけボードができ、① だけが `active`
- [ ] あとから作った班にもボードができる
- [ ] 版 0002 を流した DB とモデルが一致する
- [ ] `pytest` が全部通る
